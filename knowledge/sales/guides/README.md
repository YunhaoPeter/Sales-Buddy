# 储能销售策略与活动指引

本库为原创内部工作基线，不是公开文档目录；公司产品、授权、法律和项目事实仍需有效材料。

- [S0 线索资格与转化](KB-S0-playbook.md) · 定方向 / A01 · 阶段活动 · 把真实客户的可跟进需求与泛泛咨询分开，决定是否值得转为S1商机。
- [S1 需求发现与价值引导](KB-S1-playbook.md) · 定方向 / A02 · 阶段活动 · 把“想买储能”转成客户认可的问题、应用边界和价值假设。
- [S2 机会资格与决策链](KB-S2-playbook.md) · 定方向 / A09 · 阶段活动 · 判断机会是否值得投入，并建立预算、决策链、竞争和时间窗口的推进路径。
- [S3 售前方案与评审推进](KB-S3-playbook.md) · 定方向 / A08 · 阶段活动 · 形成客户确认的需求和技术供货边界，使方案能被评审、被比较并进入商务流程。
- [S4 投标组织与赢单准备](KB-S4-playbook.md) · 定方向 / A09 · 阶段活动 · 作出可解释的投标决策，提交完整一致且有授权的响应，而非只赶截止时间。
- [S5 合同谈判与履约准备](KB-S5-playbook.md) · 定方向 / A10 · 阶段活动 · 在可交付、可收款和获授权的边界内完成合同，确保承诺能被后续团队执行。
- [S6 销售交接与交付跟踪](KB-S6-playbook.md) · 定方向 / A10 · 阶段活动 · 把合同承诺完整移交并跟踪履约依赖，让销售继续管理客户预期和商业风险。
- [S7 验收协同与问题闭环](KB-S7-playbook.md) · 定方向 / A10 · 阶段活动 · 按合同客观完成验收并关闭遗留问题，保护客户体验和付款证据。
- [S8 回款与复购经营](KB-S8-playbook.md) · 定方向 / A10 · 阶段活动 · 按付款触发条件组织证据、承诺与升级，收回款项并保留后续客户经营机会。
- [大型储能直销：从开发机会到履约](KB-MODE-utility_scale.md) · 定方向 / A09 · 业务打法 · 识别投资、开发、集成、采购与运营角色，围绕项目关键路径组织销售。
- [工商业储能：用数据驱动价值验证](KB-MODE-commercial_industrial.md) · 定方向 / A07 · 业务打法 · 先验证负荷、经济假设、投资模式与场地，避免拿通用回本年限销售。
