# 递资源

- [C01 信息资料、模板与外部背景资源](C01.md) · 将信息请求变成解决当前项目问题的资料包，而不是泛发产品和政策链接。
- [C02 客户、供应商、EPC与项目关系入口](C02.md) · 在证据、权限和关系维护人许可下，利用经核实的协作交集帮助项目推进。
- [C03 售前、并网、工程、财务与专业支持](C03.md) · 把销售问题交给适合的专业角色，明确输入、输出和决策权限。
- [C04 客户接待、工厂、样机与案例验证](C04.md) · 让接待与展示帮助客户完成具体判断，避免只有参观没有推进产出。
- [C05 集团金融、保险担保与应收支持](C05.md) · 按资金问题类型申请真实可用的专业支持，严格区分项目融资、供应链融资和应收安排。
- [C06 政府、公共机构与正式协调入口](C06.md) · 帮助客户找到合法公开的办理、解释和沟通路径，不把资源关系当作审批保证。
- [C07 项目管理、交付、调试与运行服务](C07.md) · 在合同前就验证交付与服务能力，并把调试、培训、运行和寿命末期职责逐项交接。
- [C08 高层赞助、跨业务协同与商务授权](C08.md) · 将管理资源用于解决明确阻塞和资源冲突，形成可落实的决策或支持。
