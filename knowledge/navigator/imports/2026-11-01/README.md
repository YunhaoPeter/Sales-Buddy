# 赢单领航员知识库 Excel 内容版

版本：2026-11-01。七个模块分别提供独立 Excel，每个文件含“知识清单”和“填写说明”。首行是业务字段，无技术ID，无PPT文件依赖。

- 01_阶段定义：18条，6个字段。
- 02_阶段判断规则：46条，8个字段。
- 03_画像事项与活动：156条，8个字段。
- 04_追问问题：199条，7个字段。
- 05_M×P策略：36条，8个字段。
- 06_风险规则：122条，7个字段。
- 07_资源能力与联系：40条，11个字段。

合计617条知识。覆盖18个M/P/T阶段、36个M×P策略组合、28项既有定方向/识风险/递资源主题及衍生业务场景。场景包含项目转售、EPC代采、预算询价、PPA与设备采购并行、暂停与重招，以及欧洲、北美、中东、亚太的核实活动；延伸至交付、验收、回款和售后。

## 使用与维护

1. 按模块选择对应Excel，在“知识清单”中编辑；字段含义、必填要求、书写规范见“填写说明”。
2. 保持首行字段及顺序，一行一条知识，不合并单元格；修改前保存上一版，按模块维护版本和回退记录。
3. 本次仅交付模板和内容，不改造应用、不导入或覆盖现有运行数据。导入兼容性最终以实现的导入功能为准。
4. M1×P4/P5的SED规则和E0–E3等级定义仍待业务补齐；不据此自动升阶段或评分。
5. 资源联系人、工号和实际能力未获企业确认，全部明确待补；建议归口不能当作已验证部门或可用能力。
6. 区域场景是核实事项与销售活动指引，不代替具体国家、技术方案和项目的专业审查。
7. 内容基于仓库既有销售方法论、MPT设计和28项战略知识编制，并扩展为场景活动；不是对所有实际项目的穷尽。
