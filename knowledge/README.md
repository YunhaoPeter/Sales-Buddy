# 储能知识库

- [销售完整指引](sales/guides/README.md)：阶段关键活动、策略、产出与确认问题。
- [定方向、识风险、递资源](sales/strategic/README.md)：三类知识导航及28个专题。

- research/：联网研究、来源目录与有限摘录；research/sources/保留原来源清单。

预制PPT及标准页预览已独立到[静态PPT库](../assets/presentations/README.md)。个人上传及生成材料属于runtime/app/materials，不进入本知识库。

导出入口：`npm run knowledge:reindex`、`npm run knowledge:export`。研究资料仅作为方法背景，具体客户状态仍以CRM及销售确认内容为准。
