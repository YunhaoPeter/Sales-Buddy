# 定方向

- [A01 客户主体、开发权与项目真实性](A01.md) · 判断这是可开发的具体项目，还是泛泛采购或未经授权的中间需求，并确认我方真正的合同客户。
- [A02 应用目标、商业模式与成功标准](A02.md) · 先确定储能解决什么问题以及谁投资、运营、受益，再讨论设备配置与价值。
- [A03 土地、站点与建设前提](A03.md) · 弄清项目是否具备可推进的场址路径，以及土地、接入工程和现场条件如何影响投资与交期。
- [A04 开发许可、环境安全与审批路径](A04.md) · 把适用许可和专业责任提前纳入关键路径，避免采购完成后才发现无法建设或安全条件不匹配。
- [A05 并网接入、容量与关键时间窗口](A05.md) · 让接入主体、过程、条件和成本进入项目判断，而不是把接入申请编号视作可投运保证。
- [A06 项目融资、资本金与可融资准备](A06.md) · 识别资金缺口类别及融资前提，帮助客户形成可被专业机构评估的项目底稿。
- [A07 收益模型、交易与运行价值验证](A07.md) · 让价值判断基于可解释的输入、运行边界和敏感性，不靠泛化回收期推进。
- [A08 技术范围、集成责任与交付可行性](A08.md) · 把产品讨论转成可设计、可集成、可交付、可测试的共同基线。
- [A09 采购决策、投标与机会投入](A09.md) · 把项目可落地与我方可赢单分别验证，再决定投入、投标与客户共同计划。
- [A10 合同、交付、验收回款与生命周期闭环](A10.md) · 把销售承诺交接成后续团队可以执行和回收资金的条件，兼顾运行、服务和退役责任。
