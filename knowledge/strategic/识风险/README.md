# 识风险

- [B01 项目真实性与权责不清风险](B01.md) · 识别项目与授权链不清造成的无效投入、重复跟进和承诺风险。
- [B02 土地许可、社区与现场条件风险](B02.md) · 防止站点或适用许可尚不具备，却提前承诺设计、交付或投运。
- [B03 并网排期、接入条件与成本风险](B03.md) · 将接入未知、延迟、成本变化与设备侧依赖转成可管理的条件。
- [B04 融资、信用与资金到位风险](B04.md) · 区分项目资金可行性、买方信用和交易付款保障，避免把单一口头承诺当成全部关闭。
- [B05 收益、市场与运行假设风险](B05.md) · 识别价值判断中影响最大的未知与冲突，而不是仅给一个乐观回收期。
- [B06 技术、安全、认证与数据边界风险](B06.md) · 防止参数、验证、认证或安全责任的未知变成未经批准的设备承诺。
- [B07 采购、决策链、竞争与伙伴风险](B07.md) · 识别有技术交流但无采购路径、单线联系或伙伴能力未经证实的情况。
- [B08 合同、履约、物流、质量与变更风险](B08.md) · 识别承诺与范围、计划、责任或现场条件不一致，形成具名偏差与变更闭环。
- [B09 验收、索赔、服务与回款风险](B09.md) · 避免测试、签署、服务责任和支付条件不清导致完工后无法关闭项目。
- [B10 我方资源投入、信息与机会成本风险](B10.md) · 让资源投入与客户承诺、项目可行性和我方胜算相称，保护商业资料和团队容量。
