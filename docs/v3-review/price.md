# 用户问题
客户说竞品便宜8%，我该怎么回应？给我能用的话术和下一步。

# 回答
**先别降价。** 现在“竞品便宜8%”只有Sarah的口头转述，还没有同口径报价（容量与测量点、供货范围、服务与质保前提未对齐），此时让价等于为未知差异付费。把话题拉回“同口径比较”，同时借这次沟通拿到采购标准和签批人。

## 可直接使用的话术

**对Sarah（采购经理，先取证）**

> “谢谢反馈，这个信息对我们很重要。我想先确认一下：这8%是来自正式报价，还是初步口头报价？如果我们能把两家的容量口径、可用能量、供货边界、质保与服务年限、交付周期和付款条件放到同一张表里，我可以逐项给Northstar一个清楚的说法。如果确认是同口径，我再核对内部授权，给您正式的条件方案，而不是先给一个笼统折扣。”

**对David（技术总监，钉边界）**

> “竞品的8%差价很可能出在范围上。想请您确认三件事：额定与可用容量按哪个测量点、PCS/变压器/EMS/并网接口是否含在对方范围内、质保与服务响应是否同档。您确认后，我们把‘包含/不含/选项/待定’列成矩阵，避免后面因为缺项补差价。”

**对方坚持“先降8%再说”时**

> “可以谈，但需要一个可验证的交换条件。比如范围、付款节奏、交付批次或服务年限哪一项可以调整？我拿到您的口径后，会带着授权方案回来，不会让您等。”

避免说：竞品质量差、我们能再降、8%不算什么。

## 下一步

1. **今天对Sarah取证**：拿到竞品报价形式、报价日期、所含范围与付款条件。结果：书面或邮件确认的比较口径；拿不到就明确记为未知。
2. **明天技术澄清会（David+Sarah）**：逐项确认200MWh的可用能量测量点、系统边界与责任分工、质保与服务前提。结果：客户具名确认的范围矩阵和偏差清单，替代目前未确认的需求清单V1。
3. **会后24小时内出同口径比较表**：分“我方确定 / 竞品未知 / 客户确认差异”三栏，只填有依据的内容。结果：把价格争论变成范围与价值差异。
4. **同期问清采购路径**：评审标准、比价权重、最终签批人和下一评审日期。结果：明确谁做决定、什么时候决定。
5. **仅在同口径确认后启动让步**：向销售负责人申请可交换条件（付款、范围、服务年限），每个让步绑定一个客户承诺。结果：授权范围内的正式方案，而非现场让价。

**补充提醒**：该项目现有多个名称重复的待办（“确认采购评审路径”“取得需求基线”）和两条重复的技术澄清活动记录，动作前先认领一条，避免团队重复跟进。
