# 赢单领航员：客户项目概览与会话入口

更新日期：2026-11-01。

## 用户旅程

首页搜索结果、快捷项目和最近沟通列表先进入客户或项目概览。该页读取基础信息和当前用户的历史会话，不自动选择最近一条，也不因为没有历史而创建空会话。

概览展示对象名称、类型、编号、所属客户、地区国家、负责人、业务模式或CRM阶段和背景描述。项目额外展示当前M:P/T定位或未评估状态；CRM阶段与MPT保持独立。完整资料继续通过现有实体详情弹窗查看。

历史记录按已有时间顺序列出标题、最近问题、时间、沟通轮数及执行状态，可按标题或最近问题搜索。用户明确点击某一条后，才读取并恢复该会话。新建对话创建独立会话并进入聊天，旧会话不被覆盖。无历史页面展示首次沟通入口。

聊天返回按钮回到当前对象概览，概览返回按钮回到赢单领航员首页。对话日志中的“打开原会话”属于明确选择，继续直接打开指定会话，不强制绕回概览。

## 路由与隔离

- `/advisor/{customer|lead|opportunity}/{id}`：客户或项目概览，刷新仍恢复概览。
- `/advisor/{type}/{id}/conversations/{conversationId}`：显式选择的会话，刷新恢复同一条会话。
- 对象详情、会话清单和历史读取继续使用现有权限校验；客户和项目分别查询，不跨对象拼接历史。
- 已转化线索的历史保留，概览不提供创建新会话的入口；后续沟通应进入对应商机。
- 返回首页时立即同步地址，再刷新数据，避免立刻刷新时误恢复旧聊天路由。

## 无校验进入下一阶段

完成基础题后的“进入下一阶段”不再对当前追问题卡要求有效填写。空白题卡忽略；有文本但没有状态的内容按未明确保留；合法的已回答状态和内容保留。不用空白项伪造确认事实。

正式“提交”仍有输入校验，最终画像保存和权限/版本保护保持不变。跳过追问不自动批准阶段条件，缺口继续保留。
