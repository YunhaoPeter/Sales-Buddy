# 项目画像矩阵与固定重点事项

更新日期：2026-11-01。

## 画像界面

- M0–M5位于底部X轴，从左向右；P0–P5位于左侧Y轴，从下向上。每个轴标签显示阶段编码、名称及定义。
- 独立采购阶段位于矩阵上方，保留T1–T5连线与当前阶段标记。
- 标题与关闭按钮在弹窗滚动时冻结；颜色图例保留在矩阵下方。
- “更新记录”位于“修改项目阶段”左侧，点击展开按时间倒序的画像更新记录。
- 点击格子查看策略、风险、资源和下一里程碑，删除“带入对话进一步讨论”。
- 缩小右侧画像卡片、事项、客户资料的字体与间距；不缩小弹窗正文和问答输入区。

## 固定阶段事项

过去直接用每道问题的标题作为事实标题，侧栏因此会不断长出新栏目。现在每个阶段绑定固定重点事项清单，来源为该阶段的基础核实问题，配以固定业务名称。例如M1为土地控制、并网节点、核心许可、当前障碍与负责人。

`checkpointDefinitions`保存清单定义；`checkpointKey`用于内部归并同一事项，不在用户界面显示。每个槽位包含维度、阶段、标题、基础问题与必需/可后补分类。未有回答的槽位也显示，状态为未明确。相同阶段沿用已有定义，知识库更新不会静默重排既有画像的事项。

阶段评估的基础回答直接归到对应槽位；延伸问题要求模型指向已有槽位，补充回答仍为同一事项提供依据。没有可靠归属的原话保留在历史事实中，不新增侧栏字段。新的问题服务于固定清单的信息完整性。

日常对话画像更新提案要求模型引用已有事项，提供最新状态和合并描述，保留用户原话出处；用户确认后更新对应事项。服务器校验事项属于当前阶段，拒绝新增自由标题，合并重复槽位提案。未确认不修改有效画像，阶段调整仍需最终确认。

兼容旧数据：通过既有基础问题标题或规范名称将旧答案映射到固定事项；不删除旧回答、画像版本或用户会话。自由问答不再作为当前画像栏位；Markdown当前事项也按固定清单输出。阶段变更后旧阶段事项保留历史，仅展示新阶段的固定清单。

## 知识库与Excel

导航、面包屑及页面标题统一为“赢单领航员知识库”。移除模块清单标题下的“当前使用版本·条数·字段数”，保留明确的版本记录入口。说明区域标题统一为“字段与填写规范”。

所有模块的完整导出、历史版本导出和模板下载共用同一格式：

1. 第1行：字段标题，保持各模块现有列名及顺序。
2. 第2行：逐列对应的填写规范，注明必填/选填和书写要求，浅色背景、换行显示。
3. 第3行起：知识记录，模板为空白待填。

知识清单冻结前两行，独立“填写说明”工作表继续保留。导入器识别规范行，不将其视为知识；兼容没有规范行的旧文件。错误行号按上传文件实际位置计算，后台记录行号按新的导出格式展示。上传仍为完整模块替换，经差异确认后生效，保留版本及回退。

## 验证

服务测试核对七类模块导出与导入往返、规范行跳过、原记录内容及行数不变；固定事项始终有槽位，重复对话更新保持同一事实记录，旧自由问答不变成新增栏目。

浏览器测试核对36个格子、M/P标签与描述、两轴几何方向、采购阶段在矩阵上方、滚动后标题和关闭按钮仍可见、更新记录、移除的讨论入口、知识库新命名及填写规范标题，并覆盖原有MPT评估/画像更新/待办创建/知识导入回退旅程。

“Agent主动核实 / 下一步行动 / 猜你想问”的进一步分层为后续产品建议，本次没有修改其生成协议或按钮文案。
