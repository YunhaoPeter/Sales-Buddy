# 同轮上下文追问

主回答最终模型输出同时包含 Markdown 正文和 salesbuddy-followups JSON 代码块。服务端拆分后，正文参与原有回答规范校验，追问校验实体引用、重复问题和格式，并随回答一起持久化。追问不再独立调用模型；格式缺失或异常时仍保留主回答，不自动重试模型。工具查询循环、必要的正文校验和记忆提取仍按既有机制运行。

每轮通常生成2至3个具体追问，不设置短标题或刻意压缩内容。按钮显示完整 question，允许自动换行。点击追问仅将全文填入并聚焦输入框，用户可修改、清空或自行发送；点击不会创建消息或启动运行。发送后使用普通 user_input 来源记录。绿色创建建议仍打开草稿、经用户确认后写入 CRM。

验证：108 项单元测试通过，12 项隔离浏览器测试通过，类型检查通过。覆盖追问正文拆分、长问题保留、无额外模型请求、格式损坏保护、点击不发送及主动发送。此次未调用真实模型服务。
