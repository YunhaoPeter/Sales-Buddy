# 首页工作台实施与发布

更新：2026-11-03（北京时间）。本次在用户确认本地首页后追加授权发布云端。

## 已实现

- 默认首页改为工作台，保留项目概览、历史会话和P11入口。使用小Cue透明形象、简报及蓝白色Magic Cue卡片。
- 读取本人负责的项目、本人执行的待办、本人创建的商务活动，以及相应的画像和个人记忆；管理员和经理也默认只看本人事项。
- 每天北京时间08:00后由进程内worker检查生成，服务启动后补查；首访缺失时补生成，支持手动刷新。单用户生成串行、每日结果持久化。服务关闭时不生成，恢复后补查。
- 提醒最多每轮新增5条，每页5条。以用户、对象、原始行动内容生成稳定标识，不因AI改写文案重复。完成事项不重新进入生成候选；新的实质行动可生成新提醒。
- 点赞/点踩互斥、可取消。提醒的完成/恢复不改变CRM任务；后台刷新不覆盖用户状态。白底卡片，仅状态按钮使用蓝色/蓝灰色。
- 卡片详情展示来源。发起会话复用现有项目会话界面，自动委托以system来源保存；重复请求复用同一会话/运行，失败可重试，不提取为用户确认事实。
- 待办支持本人创建、完成、撤销、恢复和全部列表。创建复用CRM草稿确认和写入校验，固定执行人为本人，以请求标识防重复提交；不开放通用CRM字段更新。
- 日程来自CRM商务活动，按北京时间筛选，只有开始时间时仅显示时间点；支持全部日程、日期切换、记录详情、会前讨论及P11材料入口。
- 生成失败保留旧结果；模型返回不存在的候选、无效格式、或期间发生权限撤销时拒绝发布结果。提醒与简报批量事务写入，用户状态分离保存。
- 正常运行使用真实时钟；旧配置中的BUSINESS_CLOCK只对隔离的data-test-*数据库生效，避免旧演示日期冻结用户业务时间。

## 接口与存储

`/api/home-workbench`聚合首页；`/api/magic-cues`查询、详情、状态/反馈和会话入口；`/api/workbench-generations`查询/启动生成；`/api/my-tasks`查询、创建和专用状态更新；`/api/my-schedule`按日期读取。

复用SQLite documents存储，新增magic_cues、cue_states、daily_briefings、workbench_generations、cue_conversations、home_task_requests及task_status_audit集合，不重置或替换现有数据库。读取与修改均重新检查权限；个人数据归属收回后，旧提醒及关联简报也会隐藏。

## 检查与发布方式

便携测试不包含P11原生演示文稿生成；完整单元测试另覆盖该能力。工作台新增测试覆盖北京时间、去重/跨日、权限撤销、本人范围、幂等创建、状态隔离、真实受控模型HTTP协议与失败保留。浏览器测试覆盖首页、反馈/完成/撤销、待办创建、会话幂等、日程及P11入口。最终数量和云端验收结果在发布完成后记录。

本次云端发布必须保留已有的部署访问保护、内部MCP签名Cookie修复和可独立部署的PPT引擎。先检查运行任务并备份shared，在新的独立release构建，再切换current并重启唯一Sales Buddy服务；不重新导入本地数据库、记忆或素材，不修改同机其他应用。

真实邮箱、外部日历及企业个人认证不在本次实现内。现有HTTP备案拦截/证书续期问题独立跟进，不因首页发布视为解决。
