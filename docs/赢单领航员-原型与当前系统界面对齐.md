# 赢单领航员：原型与当前系统界面对齐

更新日期：2026-11-01。

正式设计源：`designs/CRM智能助手vzyh_2026.9.23.pen`。本次仅修改产品原型与设计说明，不修改应用代码、用户数据或运行配置。

## 1. 入口与项目对话

- 首页搜索结果和最近沟通记录先进入客户/项目概览，不直接打开某次历史对话。
- P10.132 项目概览、P10.133 客户概览、P10.134 无历史对话，展示对象基础信息、历史会话与新建对话入口。
- P10.42 为已评估项目的核心对话页面。会话工作台位于左侧，默认隐藏；右侧使用同一个紧凑项目画像组件。
- P10.143 展示整理建议时的加载状态与流式回答片段；P10.144 展示左侧工作台展开状态。工作台包括任务规划和本轮已查询数据。
- 报告、待办创建结果、资源建议页沿用统一侧栏，避免每种对话出现一套不同工作台。

## 2. MPT评估与重新核对

CRM实体及销售阶段与M/P/T独立。最终记录用户选择并确认的阶段；AI核实结论、缺口及描述分别记录，不因信息缺失而丢弃用户选择。

| 场景 | 原型 | 交互要求 |
| --- | --- | --- |
| 首次使用 | P10.48 | 未评估状态，明确“开始评估”入口 |
| 维度选择 | P10.52、55、56 | M、P、T分别选择，卡片含阶段名称和描述 |
| 各阶段基础核对 | P10.53–94相关页面 | M/P/T三列排列，区分必需条件和可后补信息 |
| 关键延伸问题 | P10.135、136、137 | 基础提交后直接出现问题；上一题、下一题、提交；右下角可直接进入下一维度或完成更新 |
| 历史答案回填 | P10.138 | 同阶段已有画像记录时展示答案，用户可修改 |
| 重新选择 | P10.58、107、113 | 按钮统一为“保存选择，进入核对”；与“重新评估全部维度”保持间距 |
| 单维度分析 | 各阶段结果页 | 展示用户所选阶段、核实结果和待补充事项，允许修改选择 |
| 完成更新 | P10.57 | 保存所选M/P/T后回到项目对话，展示保存反馈 |

翻页保留本窗口已填答案。只有用户点击“暂存，稍后继续”才保存续答草稿。延伸问题的“进入下一阶段”不校验当前答案；T维度对应“完成更新”。通用提交按钮统一为“提交”。

页面样例用于表达状态和交互规则，不代表将所有追问写死。实际追问应围绕固定画像重点事项的关键缺口，结合已回答内容生成，避免重复和无关细节。

## 3. 固定项目画像与更新确认

右侧统一组件：当前M:P卡片、T卡片、查看项目画像、更新项目阶段、当前阶段重点事项、本轮关联数据。

重点事项为该阶段预定义的业务事项。对话只更新对应事项的状态与最新描述，不将每个新问题增加为新栏目。状态统一为已确认、未明确、不涉及。

对话更新旅程：

1. 用户点击“根据本次对话更新画像”。
2. P10.139：Agent分析上下文，展示处理状态，尚未写入。
3. P10.106：在对话中逐项展示原值、建议值、状态与销售原话，用户选择确认项。
4. 用户明确确认后调用画像更新Skill。
5. P10.110：显示保存结果，右侧同步最新描述。

项目记忆P10.20调整为项目画像、固定事项和更新记录的展示，更新入口返回项目对话确认。个人回答偏好与项目业务事实保持分开。

## 4. 项目画像矩阵

P10.43保留M×P策略分区；M0–M5从左下向右，P0–P5从左下向上，两轴均附阶段描述。采购T时间线位于矩阵上方，每个节点展示名称和简要定义。分区颜色图例位于矩阵下方。

标题与关闭按钮固定。工具栏顺序为“更新记录”“修改项目阶段”。P10.142补充更新记录展开页，展示阶段及重点事项变更。

推进方向使用箭头示意，并附循环流动的原型注释；本次移除无法加载的外部Shader引用。静态画布表达方向与位置，不宣称静态截图包含真实动画运行效果。

## 5. 回答、猜你想问与创建操作

- 主回答优先提供与问题相关的判断、行动和可协调资源，避免大段证据堆砌。
- “猜你想问”以销售发给Agent的委托式请求表达，例如“帮我查看采购联系人的CRM信息和历史商务活动”。Agent需要向销售核实的问题放在正文或评估问答中。
- P10.140展示完整推荐问题进入输入框的状态。点击仅填入输入框，由用户修改并发送。
- 讨论建议用紫色；创建类操作用绿色。“添加待办”才进入可编辑草稿，确认后创建。
- P10.95保留现状、障碍、优先行动、资源建议；添加待办样式与P10.42统一。内部资源联系人及COME跳转仍为规划示例，不代表已经接入真实员工目录。

## 6. 赢单领航员知识库

P10.114–131保留阶段定义、判定规则、业务活动、追问、M×P策略、风险、资源等模块的列表与字段。继续沿用此前Excel清单字段，不另造一套列表。

- 模块名称统一为“赢单领航员知识库”。
- 删除“当前使用版本·条数·字段数”等无助于操作的组合标签。
- 规范标题统一为“字段与填写规范”，不把文件名拼入标题。
- P10.141补充Excel文件结构：第1行为字段标题，第2行为逐字段填写规范，第3行起为业务数据。下载数据和导入模板均遵循该结构。
- 保留按模块导入Excel、差异反馈、版本管理及回退，不增加审核发布流程。

## 7. 分区与复核

现有页面编号尽量保留；新增P10.135–144承载本轮补充状态。原型地图更新入口、评估、对话、确认、知识库的索引。P10.32–41标为历史参考，避免与最新MPT流程混用。
