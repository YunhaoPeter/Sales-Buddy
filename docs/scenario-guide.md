# 场景演示脚本
1. 打开 http://127.0.0.1:3001，选择张小小。
2. 搜索英国储能一期，打开商机OP-UK-026。
3. 提问“分析当前现状，项目为什么还推不动，下一步做什么？”
4. 检查右栏三步任务和实际关联数据。点击查看全部来源，核对商机、联系人、进展、活动、知识等。
5. 点击整理下一步待办，编辑字段并确认。复制创建记录ID，到客户360 / CRM的待办页搜索回查。
6. 新建同一对象会话，观察Memory上下文来源。后台选择演示管理员，打开记忆管理查看文件和版本。
7. 搜索德国园区储能，询问回本周期。演示应说明负荷、电费等输入不足，不承诺数字。
8. 切换李明，搜索Iberia或西班牙渠道项目，生成伙伴计划。replay为模板；live才验证开放问题与模型策略。
9. 客户级打开Northstar，观察跨业务查询与不同Scope历史。
10. 管理员场景控制台设置create_task失败或回执丢失，再验证重试不重复建单。
11. 管理员选择未转换S0线索转商机；旧线索与进展保留，新实体从S1开始。
12. 右上切换live：未配置模型时应明确报错，不用模板代替。

日期以演示业务时钟2026-10-25为基准。用户手动输入的任务日期可以编辑。
