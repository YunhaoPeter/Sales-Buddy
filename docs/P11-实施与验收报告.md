## 5. 本机试用步骤

1. 启动`npm run dev`，打开`http://127.0.0.1:3001`，选择张小小。
2. 左侧“关键会晤赋能”，搜索“英国储能一期”，选择项目并新建。
3. 示例输入：“准备30分钟英文技术交流，David和Sarah参会，重点明确系统接口责任、供货边界和交付协同，公司介绍最多一页。”
4. 根据Agent追问补充背景；完成后确认大纲和每页问题。
5. 对未匹配页，可选个人资料、生成或明确留空；其他页选择对应原Slide。
6. 生成页必须点击“确认采用本页”。所有页面选定后进入预览并导出。
7. 左侧“个人素材库”查看草稿、上传及导出。回到会晤首页可恢复最近准备。
8. “储能知识库 → 面客PPT资料库”检查10套原文件及研究来源；“销售活动指引”仍是原有策略活动库。

## 6. 运行条件与已知边界

- 生成、预览和原页导入依赖本机Codex自带Artifact Tool运行时；迁移到普通服务器必须安装兼容运行时或替换适配器。可通过`ARTIFACT_MODULE_PATH`配置模块路径。
- Windows渲染器偶尔在完成回执和所有文件写出后退出异常。本版使用独立进程，并校验回执、PPT大小及全部PNG；不完整结果仍报错，完整但异常退出保存诊断。
- 文件任务为本地串行队列；大批并发、分布式恢复和长期存储配额不属于本次单机Mock版本。
- 当前候选为规则检索，不是向量语义重排。候选是供销售选择的原页，不保证自动选到最优内容。
- 24类是目录体系，目前10类有实际文件；其余类明确待补齐。Mock文件均英文，中文目标可以生成/改写，不自动冒充已有中文原页。
- PDF/DOCX仅提取文字作为参考，没有排版转Slide和OCR；PPT中的复杂对象不做任意保真保证。
- 模型生成内容需用户逐页确认。真实产品参数、认证、公司介绍、授权案例与服务条款仍需企业材料填充。
- 测试和在线烟雾使用隔离目录，不改动主CRM记录、模型密钥或用户原有对话。
