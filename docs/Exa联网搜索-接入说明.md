# Exa联网搜索接入

日期：2026-10-27。

## 使用

销售战略参谋已新增只读MCP工具`web_search`，在线模型可在用户要求联网、检索最新公开背景或客户资讯时调用。示例：“请联网搜索美国能源部关于储能项目并网的公开资料，给我来源链接。”普通CRM分析不强制联网。

搜索结果保留网页标题、原始URL、可用的发布日期、检索时间与节选；本轮来源清单中按“外部网页”列示，标题可打开原网站。外部内容不直接作为CRM已核实事实，也不自动写入业务知识库。

管理员设置新增Exa配置区，可启用/关闭、替换密钥、测试已保存配置。密钥留空保留原值；新密钥请保存后测试。更改模型API配置不会删除Exa配置，反之亦然；版本冲突时重新读取对应配置。

## 接口与配置

- Exa官方端点：`POST https://api.exa.ai/search`，鉴权使用服务器端`x-api-key`请求头。
- 本地环境变量：`EXA_API_KEY`、`EXA_SEARCH_ENABLED`。
- MCP：`web_search(query, numResults, includeDomains?, startPublishedDate?, scope?)`。
- 已认证HTTP：`POST /api/web-search`；如传scope则校验CRM权限。
- 管理员：`GET/PUT /api/admin/settings/search`、`POST /api/admin/settings/search/test`。
- 单次最多8条结果，默认5条；每条最多2000字符节选，超时20秒。

密钥只保存在被Git忽略的本机.env，不放入前端、源码、检索参数或日志，也不返回给客户端。API服务地址固定为Exa官方域名，避免将密钥发送到任意地址。

模型仅应提交公开主题、国家和公开公司名称，不复制CRM会议原文、报价、联系方式等内部内容。接口对内部编号、邮箱及部分电话号码形式进行拦截；这不是完整的数据防泄漏系统，正式部署仍需按企业规则扩展。

失败明确返回未配置、关闭、超时、网络错误或上游HTTP错误，不以固定结果冒充联网；上游错误正文不直接返回客户端。自动化浏览器测试关闭Exa，避免消耗真实检索用量。

## 验证

真实Exa烟雾检索使用公开的美国能源部储能项目主题，返回3条真实网页结果；记录见`exa-live-smoke.json`。测试未发送CRM客户记录。新增测试覆盖密钥不回传、模型配置保留、过期写入拒绝、请求鉴权、来源和日期、URL过滤、敏感形式查询拦截、错误脱敏和关闭行为。

实现参考[Exa官方Search API](https://exa.ai/docs/reference/search)。三类知识库框架设计见《储能销售知识库-定方向识风险递资源-框架设计.md》，本次未实施对应知识库改造。
